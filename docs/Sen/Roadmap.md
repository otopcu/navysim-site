# Sen roadmap

The initial C2SIM authoring stage is delivered: metadata/weather, ship allocation/state, timed events, validation and package open/save. See the [completed six-stage migration](../Roadmap.md#c2sim-scenario-infrastructure).

Future profile work: map/route placement, terrain asset selection, condition/objective authoring, organizations/OTC, richer weather, recent-file convenience and explicit conversion if historical NSDL scenarios must be retained. These require versioned semantics and acceptance tests; historical feature lists are not current capabilities.
