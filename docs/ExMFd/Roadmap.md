# ExMFd roadmap

The initial C2SIM execution stage is delivered: validated package loading, capability/session preflight, receipt-gated initialization, controlled time, scheduled weather/failure/recovery, pause/resume/stop/restart, retry and report export. See the [six-stage migration](../Roadmap.md#c2sim-scenario-infrastructure).

Future profile work: conditional objectives/routes, OTC/organization allocation, other own-ship types, richer environment, durable journals/recovery and wider-area coordinates. A two-phase transaction or HLA time-management mode requires explicit protocol and acceptance design.
