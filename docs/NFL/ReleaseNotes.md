- Uses user export `20261018040130`, shared with MEKO, EnviFd and ExMFd. Typed injection descriptors replace EventType/Parameter1/Parameter2; the base carries EventId/TargetObjectId/Description.

## [3.1.2]

*Send FOM content over the Federate Protocol*

- Federation creation reads the local FDD and uses the explicit `FomModuleSource` content overload. NFL and MekoFd send XML bytes with a portable file-name designator; the RTI no longer receives a bare client-local file path.
- The pinned Fora.Client 20261004.0.0 supports this overload. The active FOM contract remains version 3.1.1, with no field or wire-layout changes.
- The previous path-only call fails against the current Debug RTI used by Fora.Rti.Console. Earlier tests against the older Release RTI did not expose it. Live scripts now default to the built Debug RTI; the configuration can be selected explicitly.
- Regression verification checks the complete outbound FOM bytes and retry behavior. NFL passes 63 unit checks and 27 current Debug RTI checks. EnviFd Debug and published application outputs are tested against the same strict RTI, including real MekoFd adapter/controller exchange.
- Local package: `Output/packages-built/NFL.3.1.2.nupkg`.

## [3.1.1]

*Resolve integer data type references*

- Added `Int32` and `UInt32` simple data types, represented by `HLAinteger32BE` and `HLAunsignedInteger32BE`. Eleven member references now use these data types; four-byte wire layouts and enum representations are unchanged.
- SimGe native import and composition integrity analyses resolve all member references in both navysim FOM and MekoFdSom. Schema validation alone did not detect the previous broken references.
- NFL now rejects member references to a basic representation, and tests cover the signed/unsigned boundary bytes and compatibility of the codec aliases.
- Shared FOM, SOM and documentation contain 53 definitions (including basic representations). Local package: `Output/packages-built/NFL.3.1.1.nupkg`.

## [3.1.0]

*Complete archived field contracts*

- All 69 FDD attributes and 29 parameters have explicit types. Completed four Environment GIS fields, seven Helicopter attributes and federation location text from archived EnviFd/HeliFd/OSEFd producer and consumer code.
- Added mixed navigation aid records/arrays, three signed GIS size values, double-based helicopter XYZ/Euler records, quaternion derivative and AIRBORNE=1 / ON_DECK=2 enum.
- Added typed NFL codecs, Helicopter descriptors and FederationLocationMessage; MekoFd retains its supported 35 Environment subscriptions and excludes the newly typed GIS extensions.
- NFL 3.1.0 passed 57 unit checks and 27 live Fora checks, including exchange and decoding of the twelve completed fields. SimGe FOM/SOM and the FOM/helper-library references are synchronized.
- Local package: `Output/packages-built/NFL.3.1.0.nupkg`. Archived native packets require conversion to the explicit HLA encoding; disabled/broken legacy producer conversions are not reused.

## [3.0.0]

*.NET 10 / Fora*

> Source: `Library/NFL/Code/README.md`. No date is recorded.

**Platform and dependencies**
- Targets `net10.0-windows`; keeps the WPF/Windows Forms helpers.
- Uses **Fora.Client 20261004.0.0**. RACoN, OpenRTI and their native DLLs are no longer dependencies.
- Requires a stable .NET 10 SDK (`global.json` excludes previews); `packages.lock.json` pins the dependency graph.
- Release DLL: `Output/bin/Release/net10.0-windows/NFL.dll`. Local NuGet package: `Output/packages-built/NFL.3.0.0.nupkg` (not published). Historical .NET Framework packages remain under `Deploy`.

**Fora integration**
- New `NflForaSession` and `NflObjectModel` (one per client). `StartAsync` validates the FDD, connects, creates/joins the federation, resolves typed handles, creates radio regions and declares publication/subscription. `StopAsync` resigns (DeleteObjectsThenDivest), optionally destroys the empty federation and disconnects.
- Callbacks are pumped with `session.PumpAsync(ct)`; lifecycle operations must not be called from an ambassador callback.
- Typed field encoding through `NflWireCodec`; raw `UpdateAsync`/`SendAsync` overloads accept encoded bytes, tags and optional logical timestamps.

**Shared object model (breaking changes)**
- `NavySim.xml` (FDD) is copied to consumer output and embedded for validation. Class/member names and data layouts come from modern MekoFd's `CSharp/navysim.xml`.
- `HLAinteractionRoot` corrected to **HLAreliable / TimeStamp** to match the Fora server's standard MIM. The older Meko FDD (HLAbestEffort / Receive) cannot create a federation on the new server unchanged — use the NFL FDD as the shared creation file.
- `Frigate` is `HLAobjectRoot.Frigate` with Meko/Knox subclasses; `Communication` is `HLAinteractionRoot.Communication` with five message subclasses.
- Old field names remain as aliases: Speed → Velocity, ShipName → Name, Sender → Fm, Receiver → To, Timestamp → TimeStamp, ShipNation → Nation, OtcName → OTCName, Rank → OTCRank.
- RACoN base classes are replaced by NFL descriptors in `NavySim.Nfl.Federation`; handles are nullable typed Fora handles. `CFrigateHlaObject.Posture` is now `SPosture` (six floats) instead of a string.
- Encoding: strings are length-prefixed UTF-16 big-endian; float/int/enums big-endian; DateTime is UTC ticks; ClatLong is a float plus a Unicode hemisphere (six bytes). Unspecified DateTime, invalid coordinates/enums and non-finite floats are rejected.
- Radio filtering: FormationMessage on UHF (300–3000 MHz); TaskOrd, InjectionMessage, ShipStatusReport and WeatherReport on HF (3–30 MHz); BeginToPlay is global. The Communication parent class is publish-only by default.
- Undefined legacy extension fields (e.g., Harbor/GisDbSizes) keep their FDD declarations and accept explicit `byte[]` only.
- `LocalObjects/Frigate.cs` and `LocalObjects/Scenario.cs` are retired. Backups `*.pre-net10.bak` and `*.pre-fora.bak` keep earlier definitions.

**Verification**
- Debug/Release builds and a WPF/WinForms/resource smoke check passed.
- 32 automated checks (model validation, encoding fixtures, malformed data, aliases, session lifecycle, partial-start cleanup, stale/wrong-client handles).
- 16 live checks with two Fora clients (discovery/reflection, Unicode names, posture, velocity, UTC scenario time, all five message types, BeginToPlay, HF/UHF filtering, deletion, federation cleanup).
- The local NuGet package was restored and run in a separate consumer without RACoN.
- Live tests use NFL clients only; they do not launch Stride/MekoFd or verify a full NavySim simulation.
